# Senna

Senna is the racing planet of **Face Reality**, built in **Unreal Engine 4.27**.

Pilots ride Momentum Lines, which are fast and dangerous air currents, and the best pilot should beat the best gear. The first goal is a small playable slice: one ship, one Momentum Line, and one test course.

- Lore: [docs/lore](docs/lore/README.md)
- Getting started: [docs/getting-started.md](docs/getting-started.md)
- Folder layout: [docs/project-layout.md](docs/project-layout.md)
- Senna slice design brief: [docs/design/senna-slice-brief.md](docs/design/senna-slice-brief.md)

## Roadmap

1. **Project setup.** UE4 project, Git LFS, and docs for new teammates.
2. **Design brief.** A one-page brief that turns the lore into rules for the Senna slice.
3. **Prototype.** Ship flight, one Momentum Line, and a placeholder test course, built in Blueprints.
4. **First upgrade loop.** Two or three ship parts that change how the ship races.
