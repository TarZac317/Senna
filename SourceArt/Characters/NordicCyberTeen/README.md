# Nordic Cyber Teen: rigged character (first pass)

A young man from futuristic Indianapolis: blond undercut with a Viking-style braid, blue eyes,
dark techwear jacket with glowing Elder Futhark runes (Algiz on the back, Tiwaz on the shoulder
plate), a fur mantle, leather bracers, cargo pockets and light-up boots, plus a small glowing
implant on his left temple.

## What is set up for animation

- **Skeleton (75 bones)** using the same bone names and hierarchy as the UE4 Mannequin
  (`root`, `pelvis`, `spine_01`…`spine_03`, `neck_01`, `head`, `clavicle_l`, `upperarm_l`, `lowerarm_l`, `hand_l`,
  all fingers, `thigh_l`, `calf_l`, `foot_l`, `ball_l`, the twist bones and the `ik_*` bones).
  Mannequin animations can be retargeted to it with UE4's Humanoid rig.
- **Extra bones:** `jaw`, `eye_l`, `eye_r` (look around), and `hair_braid_01`…`04` so the braid can swing with physics.
- **43 face shapes (morph targets)** with ARKit-style names, e.g. `eyeBlinkLeft`, `jawOpen`, `mouthSmileLeft`,
  `browInnerUp`, `cheekPuff`, `mouthPucker`. Eyebrows, teeth, tongue and the implant follow these shapes.
  Tongue shapes: `tongueOut`, `tongueUp`, `tongueLeft`, etc.
- **Skin weights** on the body and every clothing piece, max 4 bones per vertex.
- Rest pose is an A-pose, 1.78 m tall, facing forward.

Full morph list: browDownLeft/Right, browOuterUpLeft/Right, browInnerUp, noseSneer, eyeBlinkLeft/Right,
eyeWideLeft/Right, eyeSquintLeft/Right, cheekSquintLeft/Right, cheekPuff, cheekSuck, nasolabialDeepen,
jawLeft/Right, jawForward, chinDown, jawOpen, jawOpenStretched, mouthLowerUp/Down, mouthRollLower/Upper,
mouthShrugLower/Upper, mouthUpperUp, mouthUpperStretch, mouthPucker, mouthFunnel, mouthLeft/Right,
mouthSmileLeft/Right, mouthStretchLeft/Right, mouthFrownLeft/Right, mouthPlatysmaLeft/Right.

## Import into UE4.27

1. In the Content Browser, make a folder `Content/Characters/NordicCyberTeen` and drag `SK_NordicCyberTeen.fbx` into it.
2. In the import window: **Skeleton = None** (makes a new one), tick **Import Morph Targets**,
   leave **Import Animations** unticked, Material Import Method = **Create New Materials**, tick **Import Textures**. Click **Import All**.
3. Make the runes glow: open `M_Rune_Glow`, add a Constant3Vector set to cyan (0, 0.85, 1), multiply it by 20,
   and plug it into **Emissive Color**. Do the same for `M_Cyber_Glow_Magenta` with pink.

### Use the Mannequin's animations

1. Open the new skeleton (`SK_NordicCyberTeen_Skeleton`), click **Retarget Manager**, set **Select Rig** to **Humanoid**, then **Auto Map**. Save.
2. Open `UE4_Mannequin_Skeleton` and check its Retarget Manager also uses **Humanoid** (it usually does).
3. Right-click a Mannequin animation (for example `ThirdPersonRun`) → **Retarget Anim Assets** → **Duplicate Anim Assets and Retarget** → pick the new skeleton.

### Face and braid

- Face shapes can be set from an Animation Blueprint (Modify Curve / Set Morph Target) or driven by the free
  **Live Link Face** iPhone app, since the names follow ARKit.
- For a swinging braid, add an **AnimDynamics** node in the Animation Blueprint on the `hair_braid_01` → `hair_braid_04` chain.

## Limits of this first pass

This was generated by script, so treat it as a solid prototype and placeholder, not final hero art:

- Materials are flat colors (no painted skin, cloth or hair textures yet). The eye texture is the only image texture.
- Hair is modeled strands, not hair cards with alpha, so it reads as stylized.
- The fur mantle is simple geometry tufts; the teeth are basic.
- About 39 of ARKit's 52 shapes have a match (no mouthClose, mouthPress or mouthDimple).

For higher-end realism later: Epic's MetaHuman (UE5 only; the result can be exported but it is a big job to bring
into UE4), Reallusion Character Creator 4 (has a UE4 pipeline, paid), or hire a character artist to sculpt and
texture over this model, keeping the same skeleton.
